# CodeAlpha Basic Chatbot

A simple rule-based chatbot developed in Python as part of the CodeAlpha Python Programming Internship.

## 📌 Project Overview

This project is a basic console-based chatbot that responds to predefined user messages.

The chatbot accepts user input and provides different responses based on the message entered by the user.

## 🎯 Features

- Simple text-based conversation
- Predefined responses
- Responds to greetings
- Responds to "how are you"
- Provides its name
- Explains what it can do
- Handles thank-you messages
- Exit option using "bye"
- Handles unknown messages
- Console-based interface

## 🛠️ Technologies Used

- Python
- Functions
- While loop
- If-elif-else statements
- String handling
- User input/output
